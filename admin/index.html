גרסאות קודמות

בחרו גרסה לטעינה לעורך. היא לא תפורסם עד שתלחצו "פרסום באתר".

    איך משיגים קוד גישה?

    קוד הגישה נוצר פעם אחת ע״י בעל האתר ב-GitHub:

    1. נכנסים ל-GitHub ← Fine-grained token חדש.
    2. ב-Repository access בוחרים Only select repositories ואת הריפו של האתר.
    3. ב-Permissions ← Repository permissions מגדירים Contents: Read and write.
    4. קובעים תוקף, לוחצים Generate token ומעתיקים את הקוד.
    5. מדביקים אותו כאן. אפשר לבטל אותו בכל רגע מ-GitHub.
