# Alternative Dream – קטלוג אוהלי גלאמפינג

Hebrew (RTL), mobile-first catalog for Alternative Dream: Lotus and Bell glamping tents, size cards with specs and prices, a VAT toggle, photo galleries and a WhatsApp button.

- `index.html` – the page (plain HTML/CSS with a small inline script for the size cards, gallery and VAT toggle)
- `assets/` – photos, logo and self-hosted fonts

The original Claude Design export was a self-unpacking bundle that needed JavaScript to render; it has been unpacked into regular files so it loads directly on every browser (including iPhone).

## Publishing
GitHub Pages serves the `main` branch root: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
Live: https://femmeacademy1-code.github.io/alternative/
