# עורך פודקאסט רב-זוויות

מחבר 3 זוויות צילום לסרטון אחד, מוסיף כתוביות בעברית, ומאפשר להסיר קטעים ולתקן הכול לפני הרינדור הסופי.

## התקנה (פעם אחת, במחשב שלך)
1. התקן Python 3.11 ומעלה ו-[ffmpeg](https://ffmpeg.org/download.html) (חייב לכלול libass, זה ברירת המחדל ברוב ההתקנות).
2. `pip install -r requirements.txt`
3. שים את שלושת הסרטונים בתיקייה הזו ועדכן את השמות ב-`config.toml` (`cams`). אם יש הקלטת אודיו חיצונית, הגדר אותה ב-`external_audio` וב-`audio_source`.

## תהליך העבודה
```
python podcast.py sync          # 1. סנכרון הזוויות לפי האודיו
python podcast.py transcribe    # 2. תמלול -> subtitles.srt
python podcast.py shots         # 3. תכנית מעברי זוויות -> shots.txt
python podcast.py render --preview   # 4. תצוגה מקדימה מהירה -> out/preview.mp4
```
צפה בתצוגה המקדימה, תקן את הקבצים (בהמשך), ושוב `render --preview`. כשהכול טוב:
```
python podcast.py render        # הקובץ הסופי -> out/podcast.mp4 (+ out/podcast.srt)
```

## מה אפשר לתקן (קבצי טקסט פשוטים)
כל הזמנים בקבצים האלה הם בציר הזמן המסונכרן המלא, לפני הסרת קטעים, כלומר אותם זמנים שאתה רואה בתצוגה המקדימה ללא `cuts.txt`.

| קובץ | מה עושים |
|---|---|
| `cuts.txt` | קטעים להסרה: `12:30 13:10 הערה`. או מהטרמינל: `python podcast.py cut 12:30 13:10 "הערה"` |
| `shots.txt` | מעברי זוויות: `00:05:20 cam2`. הזווית נשארת עד השורה הבאה. אפשר להחליף, למחוק ולהוסיף |
| `subtitles.srt` | תיקון טקסט הכתוביות (עריכה בכל עורך טקסט או ב-Subtitle Edit) |

- הכתוביות מוזזות אוטומטית לפי הקטעים שהוסרו.
- כדי למצוא זמן של משפט: `python podcast.py find "חלק מהמשפט"`.
- רינדור חוזר מהיר: רק שוטים שהשתנו מרונדרים מחדש (מטמון ב-`work/`).
- `transcribe` ו-`shots` לא דורסים קבצים שכבר קיימים (כדי לא לאבד תיקונים שלך). להחלפה: `--force`.

## טיפים
- בחירת זוויות לפי אודיו (`mode = "audio"`) עובדת כשלכל דובר מיקרופון קרוב. עם מיקרופון משותף עדיף `mode = "rotate"` או עריכה ידנית של `shots.txt`.
- בתמלול ב-CPU ההקלטה של 41 דקות עלולה לקחת זמן רב. עם כרטיס מסך (`device = "cuda"`) זה מהיר. אפשר גם `model = "medium"`.
- שמות פרטיים ומונחים: הוסף אותם ל-`initial_prompt` ב-`config.toml` לשיפור הדיוק.
- הגופן בכתוביות (`font`) חייב להיות מותקן אצלך ולתמוך בעברית.
